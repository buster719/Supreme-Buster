## 1. Follow-up Questions

1. What temporal resolution thresholds have been empirically measured for visual or haptic uncertainty overlays in BCI feedback loops used in motor rehabilitation?
2. Does the minimal effective temporal resolution depend on the stroke lesion location (cortical vs. subcortical) and residual motor cortex activation?
3. How does uncertainty overlay latency interact with the known ~200–300 ms visuomotor feedback integration window in healthy adults, and is this window shifted in stroke patients?
4. What is the trade-off function between overlay refresh rate and motor task performance degradation—is it linear, threshold-based, or U-shaped?
5. Has anyone measured the effect of probabilistic confidence visualization (e.g., translucent overlays scaled to classifier confidence) on motor learning rate in BCI rehabilitation?
