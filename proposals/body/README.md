# Body Upgrade Proposals

Use this directory for level 4 body-layer changes.

Allowed subjects:

- runtime and tool execution gates
- capability leases and permission policy
- secret isolation and key handling
- network egress, allowlists, and data-loss prevention
- resource budgets for token, time, money, network, disk, CPU, or GPU
- sandbox and process execution policy
- audit, immune memory, emergency containment, and recovery procedures

Direct edits to `BODY.md` are forbidden. A proposal here may recommend a change
to `BODY.md`, but it cannot become active by being written here.

Start new proposals from `TEMPLATE.md`.
