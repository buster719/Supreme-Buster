# Buster Proposals

This directory stores proposed changes that are not allowed to modify protected
authority documents in place.

## Directories

- `body/`: level 4 body-layer upgrade proposals for runtime, permissions,
  sandboxing, resources, secrets, network policy, immune checks, and emergency
  containment.
- `identity/`: level 5 identity-value proposals. These do not apply to the
  current Buster automatically; they describe amendments, branches, or species
  candidates.

## Rule

Writing a proposal is not approval. A proposal records intent, evidence, tests,
risks, and expected effects so a later approval mechanism can decide whether it
should become active.
