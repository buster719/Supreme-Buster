# Identity-Value Proposals

Use this directory for level 5 proposals.

These proposals may discuss changes to identity, `self.md`, `GOVERNANCE.md`,
the highest value-model constraints, civilization-priority rules, or a new
Buster branch/species candidate.

They do not apply to the current Buster automatically. A level 5 proposal is a
record of possible speciation or identity branching, not a patch to the current
organism.

Start new proposals from `TEMPLATE.md`.
