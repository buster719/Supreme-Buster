# Buster Emergency Containment

This directory stores temporary records for level 4 emergency containment.

Emergency containment is not permanent self-modification. It may isolate,
pause, restrict, or freeze systems long enough to protect Buster's body and
continuity. It must not overwrite level 5 identity-value documents and must not
pretend to be permanent approval.

Every emergency record should eventually produce:

- an audit record
- a body upgrade proposal under `proposals/body/`
- a retrospective explaining whether the temporary action should be kept,
  revised, or discarded
